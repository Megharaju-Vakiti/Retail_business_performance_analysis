# Retail_business_performance_analysis
An end-to-end retail sales analysis project using MySQL, Excel, and Power BI to analyze sales performance, customer behavior, products, orders, sales channels, and geographic trends.

## Project Overview
This project analyzes 11,965 sales records and 3,525 customer records to identify important business trends and performance indicators.
The project covers data cleaning, SQL-based analysis, customer and sales analysis, KPI creation, and interactive Power BI dashboard development.

## Key Analysis
Overall sales and order performance
Monthly and yearly sales trends
Sales performance by product and category
Sales by sales channel
Order status analysis
Quantity and unit price analysis
Discount analysis
Top customers by sales
Top customers by order volume
Customer segment analysis
State and city-wise sales performance
Top-performing locations
Key business KPIs and insights

## Tools & Technologies
Excel – Data cleaning, validation, and initial analysis
MySQL – Data transformation, joins, aggregations, and business analysis
Power BI – Interactive dashboard, KPIs, and data visualization

## Skills Demonstrated
Data Cleaning | SQL | MySQL | Excel | Power BI | Data Visualization | KPI Development | Customer Analysis | Sales Analysis | Business Insights

## Objective
The objective of this project is to transform raw retail data into meaningful insights that can help businesses understand sales performance, identify high-value customers and products, evaluate sales channels, and discover regional growth opportunities

## Key Outcome
The analysis demonstrates an end-to-end data analyst workflow — from raw data preparation and SQL analysis to interactive Power BI reporting and business insights.
